# Asset Plan

The current codebase ships with a generated industrial bitmap placeholder at `apps/web/public/assets/industrial-hero.png` so layout and implementation can proceed before real photography is ready.

## Required Real Photography

- Hero: wide factory/construction image with clear subject and negative space for copy.
- Factory: production lines, material flow, warehouse, QC checkpoints.
- Equipment: cutting, welding, lifting, inspection, safety equipment.
- Projects: exterior, interior, technical details, handover moments for each case study.
- Certificates: clean scans or photographs of certificates and compliance documents.
- Team/process: site coordination, quality inspection, production planning.

## Capture Guidance

- Shoot horizontal 16:9 and 4:3 frames for hero/cards.
- Keep some clean space on one side for homepage copy overlays.
- Avoid heavy blur, dark-only scenes, and generic stock-style angles.
- Capture metadata for each project: location, year, scale, role, result, client visibility permission.

## CMS Requirements

- Every image needs Vietnamese alt text; English alt text is added when EN content is published.
- Keep source originals outside the web runtime; upload optimized versions through the CMS.
- Replace placeholders before final launch for credibility and SEO.
